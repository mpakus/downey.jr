# Архитектура

1537paperstreet проектируется как четыре слоя:

- `ps-core` уже содержит конфигурацию, реестр проектов, атомарное хранилище и
  поиск; безопасные файловые операции добавляются в P2;
- `ps-render` содержит потоковый конвейер Markdown → HTML на `pulldown-cmark`,
  уникальные идентификаторы заголовков, структуру TOC и безопасные шаблоны
  Mermaid с BLAKE3-хешем; относительные ссылки и изображения преобразуются в
  проектные `asset://` URL только после проверки через `ps-core::fsops::resolve`;
  сырой HTML очищается `ammonia` по умолчанию; верхнеуровневые блоки собираются
  примерно по 64 KiB в секции для отложенной раскладки в WebView;
- `ps-app` сейчас запускает оболочку Tauri, а типизированные IPC-команды будут
  добавлены в P4;
- `ui` содержит минимальный Svelte-каркас и CSS для пропуска раскладки невидимых
  секций документа; панели и текстовый буфер редактора относятся к последующим
  фазам.

`ps-core` и `ps-render` не зависят от Tauri. Уже реализованная запись служебных
JSON-файлов выполняется атомарно. Начиная с P2, все операции с путями проекта
должны проходить через `fsops::resolve`.

Полная архитектура, контракты и бюджеты производительности находятся в
[`docs/PLAN.md`](docs/PLAN.md). Архитектурные решения фиксируются в
[`docs/adr/`](docs/adr/).
