# Конфликты

Сейчас в приложении один вид конфликта — **имя файла** при копировании,
перемещении и импорте из Finder.

Диалог предлагает Replace, Keep Both или Skip. Чекбокс применяет выбор ко
всем оставшимся столкновениям в той же операции. Replace предварительно
снимает содержимое, которое будет затёрто.

**Конфликт версий** (`base_hash` разошёлся, пока документ был открыт):
`write_doc` возвращает ошибку и **не пишет**. Баннер «Оставить мою версию /
Загрузить с диска / Показать различия» появится вместе с UI редактора.
