# История версий и откат

Панель истории и снимки `pre_*` появятся вместе с редактором (P10). Ридер
не перезаписывает документы, поэтому откатывать пока нечего.

Разрушительные операции дерева (замена при копировании, Корзина) уже делают
служебные снимки до изменения. Пользовательского UI для отката этих снимков
ещё нет.
