# Участие в разработке

Перед началом прочитайте [`AGENTS.md`](AGENTS.md),
[`docs/PLAN.md`](docs/PLAN.md) и [`docs/CHECKLIST.md`](docs/CHECKLIST.md).

Одна задача из чеклиста выполняется в отдельной ветке и закрывается отдельным
PR. Сначала добавляется проверка, затем реализация. Коммиты используют
Conventional Commits, а код, комментарии и сообщения коммитов пишутся на
английском.

Все проверки из Definition of Done в `AGENTS.md` обязательны.
